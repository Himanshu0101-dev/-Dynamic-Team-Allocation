# -Dynamic-Team-Allocation
A company has multiple projects, each requiring a certain number of developers with specific skill levels.
You are given:

A list of projects (team size + required skill level).
A pool of developers with skill ratings.
Allocate developers to projects such that:
Each project gets exactly the required number of developers.
Skill mismatch is minimized (closest skill rating to requirement).
If allocation is impossible, return "Not Possible".
